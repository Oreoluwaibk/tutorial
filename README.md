# HTML and CSS tutorial

Static HTML and CSS practice pages. There is no package manager and no build step. Open a file in a browser.

| File | What it is |
| --- | --- |
| `index.html` | A registration form. The page title is "Registration Form" |
| `tutorial.html` | Tutorial notes, with `tutorial.txt` and `tutorial.doc` beside it |
| `pseudo.html` | Pseudo-element examples (`pseudo.css`) |
| `index.css` | Shared styles |

## View a page

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

Then open the URL the command prints.
